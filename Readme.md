## Inilah jenis proyek saya:
> **EcoPath AI** adalah website berbasis Python Flask yang membantu pengguna memahami dampak gaya hidup mereka terhadap perubahan iklim. Website ini menggunakan Google Gemini AI untuk menganalisis kebiasaan pengguna, memberikan rekomendasi ramah lingkungan yang dipersonalisasi, serta menyajikan informasi dan berita terbaru mengenai perubahan iklim.
